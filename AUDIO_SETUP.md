部分第三方音訊刻意不包含在 Public GitHub Repository。遊戲的音訊屬於可選回饋：缺少 BGM 不會阻止載入；缺少 SFX 時使用內建合成提示音或靜默繼續，不影響地圖、對話、戰鬥、結局或存檔。

請從官方提供者依適用授權自行取得素材，並放到下列 Expected Local Path。不要把取得的 Raw Audio Files 重新提交到 Public Repository。
